# cvauth-chess
Authenticated terminal chess over amateur radio AX.25 networks, using Python, Blessed and CVAuth.

# Stage	Deliverable
1	Unicode chessboard and local two-player game
2	Full keyboard-driven Blessed interface
3	Move history, undo, save/load PGN
4	RF messaging and CVAuth integration
5	Two-station authenticated chess games
6	Game invitations, player discovery and session management
7	Internet chess server integration
8	Documentation, packaging and installation
